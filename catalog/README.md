# Catalog

Content TrialAgents serves to Claude and ChatGPT through the MCP. The formats are described in [docs/CATALOG.md](../docs/CATALOG.md).

| Folder | One file per | Status |
|---|---|---|
| `requirements/` | Part I, and each member state (`de.md`, `es.md`, …) | To be provided |
| `content/` | Document type, optionally with country or language variants | To be provided |
| `word/` | Word template: a `.docx` plus a `.md` header with the same name | Default layout included |
| `workflow/` | Planning, each step type, revision and findings | Included |

Check your changes with `node scripts/check-catalog.mjs` (CI runs it too). A deploy publishes the catalog as a new release when anything changed; no plugin release is needed. Runs record the catalog versions they used.

`word/default-layout.docx` is generated by `node scripts/build-default-layout.mjs`; edit the script, not the file.
